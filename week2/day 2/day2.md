# Week 2 — Day 2 Daily Report

Date: 10 October 2026

## 1. Today's Objective
Learn JavaScript DOM Events and understand how to make webpages interactive using user actions.

## 2. What I Studied
- Introduction to JavaScript Events.
- `addEventListener()` and event handlers.
- Click events and the difference between `onclick` and `addEventListener()`.
- Mouse events: `mouseenter` and `mouseleave`.
- Input events and live input preview.
- Keyboard events: `keydown` and `event.key`.
- Form submission and `event.preventDefault()`.
- Event object and `event.target`.
- Basic understanding of event bubbling.
- Common mistakes in event handling.

## 3. Practice Exercises Prepared
- Exercise 1: Click Event — changing heading text.
- Exercise 2: Counter App — increase, decrease, and reset.
- Exercise 3: Mouse Events — changing text color on hover.
- Exercise 4: Live Input Preview — displaying typed text.
- Exercise 5: Character Counter — counting input characters.
- Exercise 6: Form Validation — checking empty username input.
- Exercise 7: Keyboard Event — displaying the pressed key.
- Exercise 8: Interactive Student Profile — updating the name and status.

## 4. What I Learned
- How JavaScript responds to user actions.
- How to register event listeners on HTML elements.
- How to use `click`, `input`, `submit`, `mouseenter`, `mouseleave`, and `keydown` events.
- How to access input values using `.value`.
- How to use `if/else` inside event handlers.
- How to prevent the default form submission behavior.
- How to use the event object to access event information.
- How to update webpage content dynamically using DOM methods.
